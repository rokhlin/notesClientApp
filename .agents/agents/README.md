# Custom Agents and Subagents

The `.agents/agents/` directory is designed for defining specialized subagent roles and profiles.

## Purpose
- Define specialized roles (e.g., Code Reviewer, Test Specialist, UI/Localization Auditor).
- Store prompts and subagent delegation workflows.

## Available Subagents

| Subagent Profile | File | Primary Responsibility |
| :--- | :--- | :--- |
| **Canvas Specialist** | [`canvas-specialist.md`](./canvas-specialist.md) | Handwritten Notes & Skia Canvas engine (Samsung Notes UX, Catmull-Rom splines, `.cmn` container format) |

## Language Convention
- All files in this directory must be written in English.
