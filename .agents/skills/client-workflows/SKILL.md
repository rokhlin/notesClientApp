# Client Workflows

Reference guide and standard procedures for working with the client application.

## Build and Run Procedures
- **Run Desktop App**: `./gradlew :composeApp:run`
- **Run Unit Tests**: `./gradlew :composeApp:test`
- **Run Web/Wasm Dev Server**: `./gradlew :composeApp:wasmJsBrowserDevelopmentRun`
