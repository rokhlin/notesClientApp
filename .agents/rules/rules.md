# Development Rules

This directory (`.agents/rules/`) stores project rules in Markdown format (`*.md`).

## Mandatory Language Rule
- All `.md` files (documentation, guidelines, rules, skills, configs) must be written exclusively in English.

## Adding New Rules
Every `.md` file in this directory is automatically loaded by the AI agent and establishes project constraints:
- Architectural patterns and conventions
- Dependency and library restrictions
- Coding standards, formatting guidelines, and testing requirements
