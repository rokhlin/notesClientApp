# Project Documentation (`docs/`)

This directory contains context files, specifications, architecture documents, and domain documentation for `notesClientApp`.

## Purpose
- Provide contextual background for AI agents, skills, and rules during task planning and execution.
- Maintain up-to-date specifications for UI/UX, client-side data flow, platform integrations (Android, iOS, Desktop, Web/Wasm), and state management.

## Structure and Usage
- **Domain & Feature Specs**: Detail feature behaviors, requirements, and user stories.
- **Architecture & Design**: Document screen flows, component hierarchy, and multiplatform setup.
- **All files must be written in English.**
